# プロジェクト名
心理テスト

## 機能
- 心理テスト
    -普通の心理テスト
- むかしむかしばなし（質問の回答によってストーリーが変わる物語）
- あれ？心理テスト？（性格診断）
    -ギャルゲーみたいな会話の選択肢の中から選ぶ。最初は「やぁ」とか「どうしたのこんなところで」とかの選択肢。その次から質問を選んでいく。「好きな子はいるの？」とか「好きな食べ物は？」とか。その前に好きな場所とか興味ある場所で「温泉」とか「合コン」とか「学校（高校、中学、小学校）」とか。それで質問の回答は
- すっぽぬけワードウルフ
- 強制適職診断
    -最初に転職したいですか？と質問がある（Yes,No,どっちでも）。その後レーダーチャート（R(赤文字)B(青文字)G(緑文字)Y(黄色文字)P(紫文字)）が右上に表示されたまま質問に答えるとリアルタイムでレーダーチャートが変わっていく。レーダーチャートは表示/非表示を切り替えられる。
    レーダーチャートの変化に伴って、背景色も変わっていく（レーダーチャートの強さの順に色を混ぜたかのような、色が移り変わっていくような感じで変わる）。背景色はくっきりさせずにぼやかしたような柔らかい感じで出す。レーダーチャートが非表示の時は、背景色はレーダーチャートの色の右回りで虹のような感じで色変化を繰り返す。
    最初の質問でNoでも「そんなことないですよね？」と食い下がる質問とかして絶対転職させる流れにする。何個かの質問のあとに職業を勧める。職業は宇宙飛行士とかyoutuberとかポケモンマスターとか。質問も心理テストっぽいテキトーなやつで、そんな関係なさそうな質問を聞く。
- 個人的MBTI
    -テキトーな質問と記述式の質問とかで性格を決める。性格は「魔王」とか「勇者」とか「社長」とか「海賊王」とか。

## 設計意図
本アプリは質問形式の心理テストを通じてユーザーのタイプ判定を行う簡易Webアプリです。
Web制作の基礎（デザイン → 質問ロジック → 結果表示 → ページ遷移）を一気通貫で構築することを目的としています。
また、UIの改善やアクセシビリティ対応、スコアロジックのリファクタリングなど、プロダクトの改修プロセスをREADMEで明示し、成長の軌跡を可視化します。
